# Daily Journal Frontend Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking. In this repo, dispatch the `journal-frontend` agent (`frontend/.claude/agents/journal-frontend.md`).

**Goal:** A keyboard-first React app that matches the "journal" design: Today/any day, Morning handover, Look back, Search, and a stubbed Assistant panel, talking to the backend over HTTP.

**Architecture:** Vite + React + TypeScript. `src/lib` holds the API client, types, date helpers and rich-text parsing. `src/components` holds presentational components ported from the design system, one folder each. `src/pages` holds containers that fetch with TanStack Query and wire shortcuts. Tests mock `src/lib/api.ts` with `vi.mock`; no network in tests.

**Tech Stack:** Vite, React 18, TypeScript strict, TanStack Query v5, React Router v6, Vitest, @testing-library/react, @testing-library/user-event, jsdom.

**Spec:** `todo_app/docs/design.md` (sections 4, 6, 7). Visual reference: `todo_app/docs/design-assets/` — `bundle.js` (component markup and behaviour), `bundle.css` (component styles), `tokens.json` (light and dark values), `README.md` (design rules), `screens/*.dc.html` (the five screens). The backend contract is in `todo_app/docs/plans/2026-10-22-backend.md`, "Shared shapes".

## Global Constraints

- Work only inside `todo_app/frontend`. It becomes its own git repo.
- Components use CSS custom properties only, never raw hex. Token names and values come from `design-assets/tokens.json`; dark values apply under `@media (prefers-color-scheme: dark)`.
- Class names follow `bundle.css` (`dj-*`). Port its rules into the component's own CSS file.
- Fonts: Source Serif 4 (500, 600), IBM Plex Sans (400, 500, 600), IBM Plex Mono (500), via the Google Fonts link in `index.html`.
- Copy: sentence case, digits, no exclamation marks, no emoji, no praise. Long date `Thursday, 22 October`; short date `Thu 22 Oct`; never numeric-only.
- Task and note text render exactly as typed, wrapping, never truncated (only URLs shorten to host+path, max 48 chars with `…`).
- Ticket ID regex `\b[A-Z][A-Z0-9]+-\d+\b`.
- "Today" = the browser's local date as `YYYY-MM-DD`, sent as `?today=` on day and review calls.
- Shortcuts never fire when the event target is an `input`, `textarea`, `select` or `contenteditable`, except Esc, ⌘/Ctrl K and ⌘/Ctrl J.
- Focus ring: 2px solid `var(--accent)`, offset 2px, on every interactive element; never removed.
- API base: `import.meta.env.VITE_API_URL` (default `http://localhost:8000`). `.env.example`: `VITE_API_URL=http://localhost:8000`.
- Every commit ends with `Co-Authored-By: Claude Opus 5.5 <noreply@anthropic.com>`.

## Review Focus

1. Pressing `N`, `X`, `[` or space while typing in the note or task input: types the character, triggers nothing. Test in Task 4.
2. Ticking a task while the API fails: the box flips immediately, then rolls back and a quiet error line appears. Test in Task 4.
3. A 300-character task with no spaces, or a long URL: wraps inside the row, no horizontal page scroll at 320px. Test in Task 2 (class check) and the manual check in Task 8.
4. Backend unreachable on first load: an error state with a retry button, not a blank page. Test in Task 4.
5. Typing in the note then switching day within 600ms: the pending text is saved to the day it was typed on, not the new day. Test in Task 4.
